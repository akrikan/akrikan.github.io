Complete MathJax LaTeX Reference for Quarto

1 Introduction

This comprehensive reference covers all MathJax LaTeX commands and syntax available in Quarto documents. MathJax supports most standard LaTeX mathematical notation with some limitations.

2 Basic Math Modes

2.1 Inline Math

Use single dollar signs for inline math: $x = y + z$ renders as \(x = y + z\)

2.2 Display Math

Use double dollar signs for display math:

$$E = mc^2$$

\[E = mc^2\]

\begin{equation}

\end{equation}

21 Tips and Best Practices

21.1 Performance Tips

  • Use $$ for display math instead of \[ and \]
  • Avoid unnecessary \left and \right when fixed-size delimiters work
  • Use \text{} for text within math expressions
  • Break long expressions into multiple lines using align

21.2 Common Mistakes

  • Forgetting to escape special characters: \{, \}, \&, \%
  • Using * for multiplication instead of \cdot or \times
  • Not using proper spacing in integrals: \int f(x) \, dx
  • Mixing text and math modes incorrectly

21.3 Accessibility

  • Use \text{} for descriptive text
  • Provide alternative text descriptions for complex expressions
  • Use semantic markup when possible
